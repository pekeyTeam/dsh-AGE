# dsh-AGE

**在 dsh 里复刻「反作弊安全组件正在扫描」的卡顿体验。**

鼠标突然拖滞、AI 回复卡在半句然后一次性吐出来、点开设置要顿一下——这些是很多人玩游戏时最熟悉的几秒钟。dsh-AGE 把它们搬进了 dsh 的网页界面，用一个模拟的扫描调度器驱动，让你在使用dsh的时候也能享受同款关怀。

## 免责声明

dsh-AGE 是一个**无聊插件**，用来在 dsh 的网页界面里模拟「安全组件扫描时卡顿」的体验。

- 它与**xxx无任何关联**，也未经其授权或认可。「AGE」是它自己的名字。
- 它**不会**读取、上传或修改任何账号数据、聊天内容或本地文件。所有卡顿效果都在你的浏览器里本地产生，刷新页面即彻底消失，卸载后不留痕迹。
- 它会**故意占用主线程 CPU**（默认档位约每分钟 15 秒），在低端设备上会明显更费电、更烫、风扇更响。
- 这不是杀毒软件。**按 `Ctrl+Alt+Shift+A` 随时叫停。**

## 安装

```sh
dsh plugin --profile web add github:<owner>/dsh-age
```

装完重启 dsh。想固定到某个版本：

```sh
dsh plugin --profile web add github:<owner>/dsh-age#<commit-sha>
```

卸载：

```sh
dsh plugin --profile web remove dsh-age
```

## 三种症状

默认（重度）档位下：**每 5–15 秒出现一次扫描，每次卡 1–3 秒。**

| 症状 | 你会看到什么 |
|---|---|
| **鼠标延滞** | 屏幕上的**指针本身**停住不动，手移动，指针冻在原位，几秒后突然出现在目前位置 |
| **文字停滞** | 同一个症状的三种形态：回复中途停住、几秒后把攒下的内容一次吐出；一块一块地跳出来而不是顺滑地爬；或者被横向拉一下再弹回。文字不丢，只是被推迟 |
| **交互停滞** | 扫描窗口内弹出的设置框、菜单延迟入场；切换会话也会顿一下 |

## 档位

卡顿不是均匀撒开的，而是**成簇**的：连续卡一阵，然后安静一阵，再卡一阵。这是真实内核扫描的节奏。

| 档位 | 单次卡顿 | 节奏 | 每分钟阻塞 |
|---|---|---|---|
| 轻度 | 0.2–0.5 秒 | 连卡约 20 次，然后安静 30–60 秒 | 约 6 秒（10%） |
| 中等 | 0.4–1 秒 | 连卡约 20 次，然后安静 15–35 秒 | 约 10 秒（17%） |
| **重度（默认）** | **1–3 秒** | **连卡 4–10 次，然后安静 5–15 秒** | **约 15 秒（25%）** |
| 地狱 | 1.5–2.5 秒 | 连卡 10–24 次，几乎不停歇 | 约 24 秒（40%） |
